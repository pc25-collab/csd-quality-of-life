# CSD Quality of Life Interactive Platform

Interactive educational platform for Citizenship & Social Development (Topic 1 Learning Focus 2: Changes and Enhancement of People's Quality of Life).

## Features
- **Interactive Curriculum Modules**: Income, Consumption, Education, Healthcare, and Poverty Alleviation.
- **Data Visualizations**: Built with Chart.js showing per capita GDP growth and higher education enrolment trends.
- **Knowledge Check Quizzes**: Interactive questions with explanations directly from PPT slides.
- **Exam Simulator**: Guided source analysis with model answers and rubric breakdowns.
- **Flashcard Hub**: Official English/Chinese definitions for curriculum key terms.
- **Gemini AI Tutor**: Integrated study assistant for custom Q&A.
